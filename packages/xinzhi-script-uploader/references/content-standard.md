# 内容生成与审核规范

## 剧名

只在读完正式剧本后生成中英文剧名，不以源小说、文件夹或下载文件名命名。标题应体现关系、身份反差或核心冲突，具有传播性，可保留暧昧、禁忌或悬念；不得虚构关系、身份、性别或重大剧情，也不得泄露结局与核心反转。英文标题面向海外市场重创，不作生硬直译。禁止 `xiaxing`、章节名等占位标题。封面已有英文标题时须逐字核对；不一致立即停止。

## genre与tags

`genre`只按核心恋爱关系选择BL、GL、GB。ABO、狼人、吸血鬼等是世界观标签，不是genre。tags从导演阐述“项目概览 → 题材类型”读取：去重，不含BL/GL/GB，同义词只保留一个，核心世界观优先，其余保持导演阐述顺序，不增加无依据的营销词。

## 集数与单元数

集数按英文正式剧本有效正文词数计算：`round(englishWordCount / 15000 * 35)`，至少1集。只统计叙述与对白正文；排除【解说词】、【对白】标签、角色前缀、标题、Markdown、制作备注、元数据、空行、占位符和纯角色标签。例：9920词为23集。

`sourceUnitCount`以英文正式剧本为基准，统计有效 `【解说词】：正文` 与 `【对白】：角色：正文`。排除文件头、项目说明、分隔线、空内容、单独省略号、纯角色、占位符、Unknown Speaker和异常多余记录。中英对照英文侧必须按顺序一一对应，数量或类型不一致即停止。

## 一句话故事、梗概和导演阐述

从正式导演阐述的“二、一句话故事”提取logline，从“三、故事梗概”提取synopsis。保留原段落与换行；标题缺失、编号变化导致不稳定时停止确认。

完整director附件原样上传。页面directorStatement由AI写为500–1000中文字符的“制作执行摘要”，保留创作核心、情绪节奏、主角表演、视觉/色彩/空间、关键道具与连续性、禁止误读和制作注意；删除重复项目概览、genre、logline、完整梗概、详细人物小传/关系表、大段世界观与重复表格。保留Markdown标题、段落和换行。已验收基线为517个中文字符。

## 试读

优先且只使用正式 `03-试读版/*-中英对照试读版.md`，不重写、概括、删节、拼接。一个完整EP对应一个 `{en,zh}`，通常4个：

```markdown
## EP01
### English
英文完整区块
### 中文
中文完整区块
```

保留段落、叙述/对白行、角色名、标签和换行。接口字段 `previewUnitLabel` 固定用“段”，EP标题保留在内容中。4个EP都安全时开放4个；只有前三个安全时只能使用一份重新提供的安全三EP正式试读，不能用开放数隐藏已进入数据的第四个风险EP。

成人与安全检查至少覆盖：露骨性行为、裸体/性器官、胁迫/性侵、过度暴力、年龄不明确的性内容、平台风险、结局或核心反转。发现风险立即停止并要求用户提供新的安全试读；禁止自动删除、改写或用可见数量掩盖。

`previewRationale`必须具体说明起点、人物、关系、世界观、冲突/钩子，以及避开的成人内容或剧透，不能写“选择前几集”之类空话。

## 封面

读取真实宽高并要求 `width*3 = height*2`，如1024×1536、2048×3072。不得相信文件名或提示词。核对角色年龄、地区、关系、页面英文标题；禁止平台水印、作者名和无关文字。出现 `_副本`、多个封面目录或不同标题时停止确认。
