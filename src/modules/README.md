# 服务端业务模块

正式业务按垂直模块组织，而不是按 controller/service 全局堆放：

- `identity`：登录、角色、白名单和一次性注册码。
- `showcase`：门户滚动海报的发布、排序和跳转配置。
- `script-catalog`：剧本资料、导演阐述、试读、状态和私有文件授权。
- `points`：心源账户、充值档位、余额流水与管理员调账。
- `commerce`：剧本购买、唯一成交、订单查询、售出锁定与安全交付。
- `agent-access`：Agent灰度资格、用户绑定Key、版本校验与持久化限流。
- `agent-import`：外部Agent草稿导入的幂等任务、失败状态和审计记录。
- `audit`：管理员操作与敏感业务留痕。

每个模块按需要包含 `domain`、`application`、`infrastructure` 和 `api`。模块之间通过公开的应用服务或稳定契约协作，不直接访问彼此的内部实现。HTTP 路由只做协议转换，数据库与文件系统只在服务端基础设施层访问。

外部Agent只允许调用 `/api/agent/v1`。它可以为Key所属用户创建价格为0的草稿，但不能定价、发布或调用网页管理接口；这些边界必须由服务器校验，不能依赖Skill是否被修改。
