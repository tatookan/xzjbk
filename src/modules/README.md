# 服务端业务模块

正式业务按垂直模块组织，而不是按 controller/service 全局堆放：

- `identity`：登录、角色、白名单和一次性注册码。
- `showcase`：门户滚动海报的发布、排序和跳转配置。
- `script-catalog`：剧本资料、导演阐述、试读、状态和私有文件授权。
- `commerce`：积分、用户折扣、充值、购买和售出锁定。
- `audit`：管理员操作与敏感业务留痕。

每个模块按需要包含 `domain`、`application`、`infrastructure` 和 `api`。模块之间通过公开的应用服务或稳定契约协作，不直接访问彼此的内部实现。HTTP 路由只做协议转换，数据库与文件系统只在服务端基础设施层访问。
